# **App Name**: NextChat

## Core Features:

- Chat Interface: Display a clean and intuitive chat interface with a message input field and a display area for the conversation.
- AI-Powered Responses: Integrate a Large Language Model (LLM) to generate responses based on user input. The LLM acts as a tool to provide relevant and coherent answers.
- Session History: Implement a simple mechanism to store and display the conversation history within the current session. This history is not persisted.

## Style Guidelines:

- Primary color: Neutral white or light gray for the background to ensure readability.
- Secondary color: Darker gray for text and UI elements to provide contrast.
- Accent: Teal (#008080) for interactive elements such as the send button and message highlights.
- Use a clean and modern layout with clearly defined sections for input and output.
- Use minimalist icons for actions like sending messages.
- Subtle animations for message transitions to enhance user experience.
